# Eunoia
UCI Chess Engine written in Go

Eunoia (/juːˈnɔɪ.ə/) is a Greek word meaning "beautiful thinking".

## Requirements
- Go 1.26.5 or newer
- Working computer (optional)

## Build
Build natively with:
```bash
make
```
Cross compile with:
```bash
make windows
make linux
```
